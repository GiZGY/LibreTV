# 广告过滤与影片时间轴

## 已确认的代码问题

当前旧过滤器删除包含 `#EXT-X-DISCONTINUITY` 的每一行，但保留全部
`EXTINF` 和分片地址。这并不是识别后移除广告，而是移除了播放器处理
时间戳重置、轨道变化所需要的边界；也误删 `DISCONTINUITY-SEQUENCE`。
清单声明时长可能仍完整，但解封装后的时间轴可能重叠、缩短或提前结束。
具体影片是否同时存在上游缺片，需要原始清单及实际媒体样本确认。

旧过滤函数逐字返回输入，旧偏好不会重新激活删标记规则。
2026-09-06 的候选实现保留默认清单 loader，分片 loader 只旁观字节，
原样转发请求回调；已确认广告通过 seek 跳过，不改写清单。

## 已实现的内容指纹方案

- `js/ad-guard.js` 先用整组时长序列定位候选，再验证每个分片的 SHA-256。
  时长和 URL 都不是跳过依据，必须整组内容逐片完全匹配。
- 使用 HLS 已下载的字节，不额外下载视频。观察点位于默认 loader 的
  onSuccess 转交之前，避免工作线程转移 ArrayBuffer 后无法校验。
- 同 URL 的下一次出现也独立校验，不能用前一次广告的命中替尚未下载的
  新分片背书，避免同地址动态换成其他内容后误跳。首遇时可能短暂露出广告，
  取决于缓冲领先量，不声称无缓冲或完全无闪现。
- `js/ad-rules.js` 是经过内容确认的整组指纹库；规则有审核日期与失效日期。
  同样的广告即使换了域名或出现在其他影片，也可通过相同内容匹配。
- 使用 HLS 更新后的媒体坐标。未知、部分匹配、过期规则、异常边界、
  直播、无法 seek 的情况不跳过。识别上限限制了候选和单分片内存开销。
- 跳过后提供撤销，不刷新页面，不重建播放器；关闭开关后立即不再跳转。
  播放地址切换或播放器销毁会清理事件、提示和异步结果。
- 内容指纹在当前播放器内存中使用，不上传观看信息。

## 真实样本（2026-09-06）

魔都《X战警：天启》（CMS ID 47050）的清单共 4379 个分片，声明时长
8753.505 秒。同一组 9 个分片重复出现 9 次，每组 17.568 秒。
魔都《飞驰人生2》（CMS ID 20246）中也出现同一组分片 9 次。
首、中、尾抽帧显示棋牌/博彩推广，全部 9 个分片的内容摘要已校验。
不是完整播放影片后逐个标记，也不是把所有断点当广告。

本地 Chrome、项目自带 HLS.js、开启工作线程实测：第一个广告区间自动跳过，
时长保持 8753.505 秒；快速定位至末段后可到达完整片尾。解码后的最终时长
8753.780 秒，与清单相差约 0.275 秒，不是截断或坍缩。
末段单独记录到自动 seek：从 8734.103 秒的测试定位，到 8753.780 秒的
广告跳过终点；不只是等待广告自然播完后检查 ended。

其他源的同名影片：暴风、极速搜索返回影片，但测试网络无法取到媒体清单；
百度本次关键词未返回该影片，华为吧连接失败。不能据此认定这些版本无广告，
也不能声称已经验证所有源。

## 覆盖边界

首批仅确认一种重复广告素材，不等于所有广告均可自动识别。
不同转码、不同分片边界、加密或新素材会使精确指纹不匹配，安全降级为保留。
原生 Safari HLS 路径尚未做真机验证，不能把 Chrome 结论等同于 iPhone 验收。
硬编码在正常画面上的广告水印不能通过跳片去掉，否则会一起丢失正片。

后续候选发现应批量分析清单、聚类跨影片重复片段，少量抽帧和音频复核后
生成版本化指纹规则。感知哈希/OCR/语音只能产生候选，不能直接授权删除。
这类离线分析适合独立 bridge 后台，不能放进 Vercel 的每次播放请求。

## 推荐方案

保留原始清单和全部解码边界，建立经过验证的广告时间区间，在播放到
区间时跳到结束位置。保留原始进度坐标，允许用户返回或关闭跳过。
这能避免清单改写损坏时间轴，但 seek 仍可能需要缓冲，不保证完全无感。

识别依据优先顺序：

1. 已验证来源的明确广告标记及成对起止信息；普通 DATERANGE 不等于广告。
2. 来源限定、版本化、有失效日期的广告路径或内容指纹规则。
3. 多影片重复媒体指纹、音视频特征和 OCR 作为候选证据，经验证后入规则库。

短时长、换域名、分辨率改变、DISCONTINUITY 单独出现都不足以自动跳过。
候选自动发现可以放在 bridge 后台；不在 Vercel 请求期间执行全片分析。
没有明确结束点、超出完整时间轴或边界不确定时不自动跳转。
规则更新必须可回滚，误判反馈应能定位规则版本。

## 验证与下一步

- `node scripts/smoke-ad-timeline.mjs`：加密清单、CRLF、序列标记、边界和末片保持不变。
- `node scripts/smoke-ad-guard.mjs`：整组校验、部分/错误匹配、撤销、关闭、
  过期、异步销毁、透明 loader 转交、时长和原清单不变。
- `node scripts/audit-hls-ads.mjs <媒体清单.m3u8> [...]`：批量列出重复序列，
  输出时间和摘要，不把 URL 中的鉴权信息写入报告。候选不伪装成已确认广告。
- 验收覆盖广告前后 seek、连续播放至末片、切换清晰度、AES-128、原生 Safari。
- 保留未知内容优先；不能用总时长上限证明被跳过的内容一定是广告。

回退时应关闭 `verifiedAdSkippingEnabled` 或停用新 guard，继续保留默认 HLS
时间轴，不恢复删除 DISCONTINUITY 的旧实现。
