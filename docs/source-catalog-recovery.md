# 源目录与本地选择

## 问题与修正

内置目录包含 20 个普通源（18 个 CMS 源、2 个电视桥接源），另有隐藏测试源。
2026-09-06 完成目录恢复时为 25 个；之后经复查退出 5 个失效或不支持搜索的入口。
源目录由版本化前端 bundle 发布，不由 localStorage 提供或删除。

旧代码存在两条可复现的缩减路径：质量检测自动将勾选覆盖为最多 5 个通过者；
未选中的 0 分源被默认隐藏。一次网络故障即可让大部分源在设置中消失。
全新空存储仍应显示全部目录，不能把所有“只有 3 个”的反馈都直接归因于此。

修正：完整目录始终可见，检测仅更新质量排序，不覆盖用户选择。总数与已选数
分别展示。旧的隐藏偏好不再影响目录，0 分记录 30 分钟过期，其余质量记录
24 小时过期。源 ID 失效时归一化并恢复默认，明确的空选择仍保留。

“恢复默认选源”只重置勾选、检测和失败冷却记录，保留观看记录、自定义源、
认证信息。重置会使在途检测结果失效，避免旧测量重新写回。该按钮不是更新
网站版本的替代品；发布仍依赖 HTML 引用新的内容哈希资源。

## 验证

- `npm run smoke:source-catalog`：空存储、破损存储、失效 ID、显式空选择、
  自定义源、三源选择、全部 0 分、旧隐藏设置、过期检测、恢复后可重试。
- 本地 Chrome 渲染实际首页 bundle：新用户显示 25 / 已选 6；旧 0 分记录
  显示 25 / 已选 3；点击恢复后显示 25 / 已选 6（清理前版本）。
- 清理后 Chrome 验收：旧记录含 5 个退出源、暴风和一个自定义源，显示
  20 个内置 / 已选 2；恢复后显示 20 / 已选 6，自定义源定义仍保留。
- `npm run quality`：构建、完整回归、原性能预算、依赖漏洞检查。

目录完整不等于每个第三方源此刻可播；搜索的超时与播放验证状态仍如实处理。
不为了凑满数量把坏源结果标记成可播放。

在复查中返回有效搜索结果；华为吧、魔爪、七七、小猫咪的 TLS 失败不足以证明
永久停运，未按单次网络错误删除。樱花搜索拒绝但片库可取，也未判为死源。
历史播放记录不改写到其他源 ID；已退出源的显式 API 请求报错，不访问失效入口。
缺省 API 来源改用仍在目录中的极速；推荐卡片不再强制添加已退出的 `dbzy`。

移除两个入口中历史性的无条件搜索屏蔽，改用片名相关性校验；若上游再次忽略关键词，
不相关短剧仍被过滤。普通关键词搜索、旧缓存迁移、退出源不发请求均有回归测试。
